OBJECT DETECTION

Finding what is in an image, and exactly where.

Image classification answers "what is this image?" with one label. Object localisation adds one box. Object detection finds every object of interest, giving each a class label, a bounding box and a confidence score. Segmentation (pixel-level masks) is a separate topic.

IMAGE→MODEL→BOUNDING BOXES→CLASS LABELS→CONFIDENCE→FINAL DETECTIONS
About the images: this file has no network access, so every demo uses a generated street scene drawn on a canvas. The detections shown are hand-defined to teach the ideas; they are not output from a trained model. Section 7 shows how to get real ones.

01 — DETECTION VISUALIZER + CONFIDENCE THRESHOLDImage → boxes, labels, scores

A detector outputs many candidates, each with a score. A confidence threshold keeps only those at or above a value. Low threshold: more detections, including false ones. High threshold: fewer, more reliable ones, but real objects can be missed.




02 — BOUNDING BOX EXPLORERCoordinates in image space


Image space has its origin (0,0) at the top-left, x grows right and y grows down. A box is stored as corners (x1,y1,x2,y2) (Pascal VOC, torchvision), or as (cx,cy,w,h) (YOLO, usually normalised to 0–1). Drag the box; drag its bottom-right square to resize.





03 — IoUIntersection over Union


IoU = area of overlap ÷ area of union, from 0 (no overlap) to 1 (identical). It scores how well a predicted box matches the ground truth: a detection usually counts as correct when IoU ≥ 0.5 (and the class is right). It is also used inside NMS and in mAP. Drag and resize both boxes.


Blue = box A (ground truth), orange = box B (prediction), green = intersection.



04 — NON-MAXIMUM SUPPRESSIONOne object, one box


Detectors fire several overlapping boxes on the same object. NMS: (1) sort by confidence, (2) keep the best, (3) discard every remaining box of the same class whose IoU with it exceeds a threshold, (4) repeat with what is left. Move the IoU threshold.


Green = kept. Red dashed = suppressed. Too low a threshold merges neighbouring objects; too high leaves duplicates.

06 — YOLO, SSD, FASTER R-CNNDetector comparison


YOLOSSDFaster R-CNN


TypeSingle-stageSingle-stageTwo-stage


IdeaPredict boxes and classes for the whole image in one forward passSingle pass, predicting from several feature-map scales with preset anchor boxesA Region Proposal Network suggests regions, then a second head classifies and refines each


SpeedVery fast (real-time)FastSlower


AccuracyHigh in modern versions; historically weaker on small objectsGood; multi-scale helps small objectsStrong, especially localisation, at higher compute cost


UseVideo, robotics, edge devicesMobile and embeddedOffline analysis, accuracy-critical tasks


Single-stage: one network directly outputs final candidates, so it is simpler and faster. Two-stage: propose regions first, then classify them, which usually costs speed but can improve accuracy. Modern single-stage models have narrowed the accuracy gap considerably.



07 — YOLO INTUITION"You Only Look Once"


Simplified view: the image is divided into a grid. The network (a CNN backbone extracting features, then a prediction head) outputs, for locations across the image, a box, an objectness/confidence value and class scores. Candidates are then filtered by threshold and NMS. This is an intuition only: real YOLO versions differ (anchors vs anchor-free, multiple scales, different heads). Click grid cells.


Click a grid cell.
Training: images with labelled boxes are fed in, predictions are compared to labels with a loss (box, confidence, class), and weights are updated by gradient descent. Inference: weights are fixed; the model only predicts, then thresholding and NMS run. Datasets such as COCO provide annotations (class + box per object).



08 — REAL-WORLD APPLICATIONSWhere it is used




Autonomous vehicles
Cars, pedestrians, cyclists, traffic lights and signs, to plan safe motion.


Surveillance
People, vehicles, left objects, for alerting and counting.


Traffic monitoring
Vehicle counts and types for signal timing and congestion analysis.


Retail
Products on shelves, stock gaps, checkout items.


Industrial inspection
Scratches, missing parts, misaligned components on a line.


Robotics
Objects to grasp or avoid, with box positions guiding the arm.


Medical / assistive
Lesions or nodules flagged for review; obstacles and signs for navigation aids. A clinician makes the decision.


Drone vision
Small vehicles, people or crops seen from altitude, where objects span few pixels.



09 — PYTHON + OPENCVCode


Traditional OpenCV (thresholds, edges, contours, Haar cascades) uses hand-designed rules. Deep-learning detection uses a trained network that learned features from data. OpenCV can draw results and can also run some exported networks via cv2.dnn.
