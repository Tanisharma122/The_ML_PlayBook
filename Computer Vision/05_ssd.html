SSD

Single Shot MultiBox Detector. One pass, many scales: small objects from big feature maps, large objects from small ones.

Big picture

Detect at every scale, in one shot

Like YOLO, SSD skips region proposals. Its key twist: it attaches detectors to several feature maps of different sizes, so each map specializes in objects of a matching size.

Implementations may tweak the scales (for example a smaller first scale), so treat the numbers as the paper's design.

Math

Loss, and why negatives need mining

Multibox loss

L = (1/N) · ( L_conf + α · L_loc )
  • L_conf: softmax over C + 1 classes (the +1 is background)
  • L_loc: Smooth L1 on the 4 box offsets, positives only
  • N: number of matched boxes, α: balance weight (1 in the paper)

Hard negative mining

Almost every default box is background. Using them all would drown the few positives. SSD sorts negatives by loss and keeps only the hardest, at about 3 negatives per positive (see the counts in Demo 2).

Data augmentation

Random crops, flips, zoom-in and zoom-out, and color changes. Zoom-out creates small training objects, which boosted accuracy on small objects.

Context

How good is it, and how does it compare?

In the original paper, SSD300 reached about 74% mAP at about 59 FPS on Pascal VOC 2007, and SSD512 about 77% mAP. For its time that matched Faster R-CNN's accuracy at a much higher speed (results depend on the paper's hardware and setup).

MobileNet-SSD

Swaps the heavy VGG-16 for MobileNet, so SSD runs on phones and small boards.

SSDLite

Replaces regular convs in the prediction layers with cheaper depthwise-separable ones for even lower cost.

Strengths and limits

Fast, simple, multi-scale. Sensitive to default box design, many boxes to balance, and still tricky for tiny objects.

Revise
Self-check


What does "single shot" mean?Boxes and classes are predicted in one network pass, with no separate region-proposal stage.


Why multiple feature maps?Each map has a different resolution, so it suits a different object size: large maps for small objects, small maps for large objects.


What are default boxes?Preset boxes of several scales and aspect ratios at every map location. The network predicts class scores and 4 offsets for each.


Why C + 1 classes?The extra class is background, needed because most default boxes contain no object.


How are positives chosen?The best-IoU default box for each truth box, plus every default box with IoU above 0.5.


Why hard negative mining?Negatives vastly outnumber positives. Keeping only the highest-loss negatives (about 3 per positive) balances training.


How many default boxes does SSD300 have?8,732 = 38²·4 + 19²·6 + 10²·6 + 5²·6 + 3²·4 + 1²·4.


Common mistakesForgetting the background class; drawing boxes without scaling back to the original image size; poorly matched default box scales for your objects; expecting top accuracy on very small objects.
