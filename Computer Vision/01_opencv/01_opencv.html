Demo 1

An image is just a grid of numbers

Each square is one pixel of a tiny 8×8 grayscale image (0 = black, 255 = white). Hover to read a value, then drag the slider to brighten or darken the whole image.

Hover over a pixel

img = cv2.imread("tiny.png", 0)
print(img.shape)        # (8, 8)
img[3, 4]               # row 3, column 4
# brightness: add β, clipped to 0-255
bright = cv2.convertScaleAbs(img, alpha=1, beta=β)

Values never go below 0 or above 255. That is called clipping.

Mistakes almost everyone makes




Colors look swapped
You treated BGR as RGB. Convert with COLOR_BGR2RGB before Matplotlib.


Wrong resize shape
cv2.resize takes (width, height), but img.shape is (height, width).


imread returns None
A wrong path gives no error. Always check if img is None.


Window won't show
Call cv2.waitKey(). On servers or Colab, use the headless build and Matplotlib.
